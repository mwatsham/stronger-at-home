Accessibility

This website targets the Web Content Accessibility Guidelines version 2.2 at level AA.

The accessibility target

The site is designed to support keyboard navigation, visible focus, text resizing, clear headings, labelled form controls and reflow on small screens. The target does not mean that every accessibility problem has already been found.
