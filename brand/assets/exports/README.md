# Approved logo exports

Approved by Melanie Watsham on 6 September 2026. These are PNG files only. The
exact approved hashes are recorded in `brand/assets/manifest.json`.

## Which file to use

| Use | Recommended file |
|---|---|
| Website or wide digital header on a light background | `logo-primary-transparent-1024.png` or `logo-primary-transparent-512.png` |
| High-resolution document or print artwork | `logo-primary-transparent-2048.png` (300 dpi metadata) |
| Email signature | `logo-email-transparent-600.png` |
| Social profile or large square mark on a light background | `logo-secondary-transparent-1024.png` or `logo-secondary-transparent-512.png` |
| Social profile or square mark on a dark, photographic or uncontrolled background | `logo-secondary-contained-1024.png` or `logo-secondary-contained-512.png` |
| Browser, app or shortcut icon | the nearest `logo-secondary-contained-*.png` size |

Choose the smallest file that is at least as large as its rendered size. Do not
enlarge a smaller PNG.

## Usage rules

- Use transparent files only on light, plain backgrounds.
- Use an opaque or contained version on dark, photographic or uncontrolled backgrounds.
- Do not redraw, trace, recolour, distort or change the relative geometry.
- Do not create or distribute SVG versions.
- Keep the complete primary lockup intact; use the secondary files when the standalone mark is needed.
- In alt text, metadata, ordinary prose and spoken use, write `Stronger at Home Physiotherapy` rather than `Stronger@Home`.
- Do not use the `®` symbol.

These files are approved assets, but using them in a website or production
release still requires that release's normal approval.
