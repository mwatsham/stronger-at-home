# Approved logo exports

Current primary layout v3 was approved by the project sponsor on 7 September
2026 (D-41). The wordmark is 75% of the symbol height, vertically centred with
the approved narrow gap. The standalone marks retain Melanie Watsham's
6 September approval. Core exports are PNG; the review-profile pack also
provides a JPG for upload compatibility. Exact hashes are in
`brand/assets/manifest.json`.

## Which file to use

| Use | Recommended file |
|---|---|
| Website or wide digital header on a light background | `exports/logo-primary-transparent-1024.png` or `exports/logo-primary-transparent-512.png` |
| High-resolution document or print artwork on a light background | `exports/logo-primary-transparent-2048.png` (300 dpi metadata) |
| Wide primary logo on a dark, photographic or uncontrolled background | `source/logo-primary-raster-v3-2048.png` or `source/logo-primary-raster-v3-512.png` |
| Email signature on a light background | `exports/logo-email-transparent-600.png` |
| Social profile or large square mark on a light background | `exports/logo-secondary-transparent-1024.png` or `exports/logo-secondary-transparent-512.png` |
| Social profile or square mark on a dark, photographic or uncontrolled background | `exports/logo-secondary-contained-1024.png` or `exports/logo-secondary-contained-512.png` |
| Browser, app or shortcut icon | the nearest `exports/logo-secondary-contained-*.png` size |

Choose the smallest file that is at least as large as its rendered size. Do not
enlarge a smaller PNG.

## Usage rules

For review sites requiring a wordmark, use
[`review/review-profile/stronger-at-home-review-profile-1024.png`](review/review-profile/stronger-at-home-review-profile-1024.png)
or its JPG counterpart. A 1200 × 500 wide PNG is supplied alongside it.
These are centred on `#F9F4F2` with clear space for common circular crops;
small endorsement text will be less legible in very small thumbnails.

- Use transparent files only on light, plain backgrounds.
- Use an opaque or contained version on dark, photographic or uncontrolled backgrounds.
- Do not redraw, trace, recolour or distort. Retain the approved v3 proportions
  and spacing for primary artwork.
- Do not create or distribute SVG versions.
- Keep the complete primary lockup intact; use the secondary files when the standalone mark is needed.
- In alt text, metadata, ordinary prose and spoken use, write `Stronger at Home Physiotherapy` rather than `Stronger@Home`.
- Do not use the `®` symbol.

These files are approved assets, but using them in a website or production
release still requires that release's normal approval.
